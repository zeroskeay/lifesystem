# 见微 · Life System

> 记录当下 · 看见规律 · 掌控生活

## 项目简介

见微是一款面向个人的轻量生活记录应用，帮助你从每天很小的事情里看见生活的变化，并通过评分与趋势回顾自己的生活节奏。

## 功能

- **首页概览**：查看当天状态、体验评分、近 7 天趋势和一句话记录。
- **分类记录**：在记录页切换五个生活维度，使用评分、时长、文本和待办事项补充细节。
- **任务记录**：支持最多 3 项当天待办，并可直接勾选完成状态。
- **数据统计**：查看 7 天、30 天和 90 天的生活评分趋势及分类数据。
- **本地数据**：数据默认保存在浏览器或应用本地存储中，无需注册账号。
- **数据管理**：支持导出 JSON 备份和恢复数据，也支持浅色与深色主题。

## 开发与运行

项目使用原生 HTML、CSS、JavaScript 构建，并通过 Capacitor 打包 Android 应用。

```bash
npm install
npm run cap:add
npm run cap:sync
```

直接使用浏览器体验时，可将 `www` 目录作为静态网站目录打开或运行本地静态服务器。

## 数据与隐私

应用不依赖后台服务，记录内容只保存在当前设备。清除浏览器站点数据或卸载应用前，请先在“设置”中导出备份。
