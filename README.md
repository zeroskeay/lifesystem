# 生活系统 · Life System

> 记录当下 · 看见规律 · 掌控生活

v1.01：完善记录编辑、日期限制、趋势图和移动端交互。

## 核心
- 首页：今日状态、体验分、7天趋势、一句话记录
- 记录：生活轨迹列表与分类筛选
- 统计：7/30/90天趋势、SVG趋势图、SVG雷达图、本周数据
- 设置：本地数据导出、隐私与应用信息
- 数据只保存在本机
- 无登录、无后台、无广告
- 无自动更新/升级提示机制
- GitHub Actions 自动构建 APK 并发布到 Releases

## 技术
HTML / CSS / JavaScript + Capacitor + Android

## 说明
“升级项目”指更新本项目代码与功能版本；本版本不包含 App 内的升级引导或自动检查更新功能。
